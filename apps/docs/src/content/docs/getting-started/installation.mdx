pathway ships as three Rust crates and one npm package. Both public surfaces
are versioned from a single source of truth: `[workspace.package] version` in
the root `Cargo.toml`.

## JavaScript

Requires Node 24 or newer, or Bun 1.3+. The Phase 1 npm package is a single
package whose build places the native addon in `dist/`; platform-specific npm
packages are a later release concern. The current runtime evidence is GitHub
run [37382716742](https://github.com/Archont561/pathway/actions/runs/37382716742):
Node 24/26 and Bun 1.3.11/1.4.2 pass on Linux, macOS and Windows, with
packed-install smoke tests on all three operating systems.

:::caution[The npm package is not published yet]
The package exists in this repository but is not on a registry. To try it from
a clone:

```sh
# in a clone of the repository
bun install
bun --cwd packages/path build:native
bun --cwd packages/path build
node packages/path/test/node-smoke.mjs
```

`engineAvailable()` returns `false` rather than throwing when the `.node` file
has not been built, so importing the TypeScript package in a fresh clone is
safe. The packed-install smoke test in
`.github/workflows/runtime-matrix.yml` is the executable distribution check.
:::

## Rust

```toml
# Cargo.toml
[dependencies]
pathway-fs = "0.1"
```

The ergonomic surface is `pathway-fs`; the engine core is `pathway-fs-core`;
`pathway-fs-engine` is the N-API bridge and is **not** published, because a
`cdylib` is not something you can depend on from Rust. The names
`pathway-fs` and `pathway-fs-core` are reserved and their manifests are
publishable, but neither crate has had its first crates.io release yet.

## Building from source

```sh
pixi install            # all environments, from the lockfile
pixi run build          # the native addon, the TypeScript packages, these docs
pixi run build-release  # every Rust crate, release mode
```

## Versions

These docs describe v{version}. The number is read at build time from
`[workspace.package] version` in the repository's root `Cargo.toml` — the one
place the version is written down — so the site cannot drift from the code it
documents.
