**pathway** is a filesystem API with two surfaces over one engine: a
TypeScript/Bun/Node package of `Path` objects, and a Rust crate with the same
ergonomics for Rust callers.

The engine is native (Rust) and the boundary is deliberately coarse — bulk
operations only, never a single string operation across the FFI seam. See
[Architecture](/concepts/architecture/) for why that is the whole design.

:::caution[This is an early release]
The repository is in Phase 1. `Path` supports string operations, file I/O,
typed serializers, and per-filesystem serializer registries. Native traversal
and fused hashing are implemented when the addon is built. Rust atomic I/O,
sandboxing, locking, and temporary-directory APIs remain planned scaffolds.
The docs below describe what is true today, not what is planned.
:::

These docs describe v{version} — the version is read from the build
environment, not written into the site.
