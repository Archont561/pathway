## 2026-09-30
* **Decision — public names (Step 0 sign-off, partial)**: npm **`@archont561/pathway`** (the scope is lowercase because npm rejects uppercase in package names; unscoped `pathway` on npm is taken) and crates.io **`pathway-fs`** (ergonomic Rust surface) + **`pathway-fs-core`** (engine core) + `pathway-fs-engine` (NAPI glue, `publish = false` forever) — `pathway` on crates.io is squatted by a 2022 placeholder (v0.0.0), hence the `-fs` family; the crates.io *reservation* is still outstanding. Also: the addon binary is `pathway.<platform>.node` via `napi.binaryName` in the package manifest, and `napi build` is wired into turbo (`build:native` task, debug default + release variant) and pixi (`pixi run build-native`). The hand-written loader's platform-suffix logic was wrong (rust triple vs NAPI-RS npm spelling) and now computes `linux-x64-gnu` / `darwin-arm64` / `win32-x64-msvc` correctly. Updated: [phase-plan.md](/implementation/phase-plan.md) (Step 0 items checked off), plus name references across the bundle.
