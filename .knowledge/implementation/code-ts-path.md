# TypeScript API Implementation

## Overview

This document contains the production-grade TypeScript implementation for
the `Path` class, `Serializer<T>` interface, `WalkIterator`, and supporting
types. All path string manipulation uses `pathe`. All I/O-heavy operations
delegate to the NAPI-RS Rust engine.

> **Sept 2026 audit — fixes applied to this reference implementation:**
> 1. **Binding loader:** the 2025 draft did `require("@archont561/pathway")` from
>    inside `@archont561/pathway` — a circular self-require (the `.node` binary
>    lives in the platform packages, not the root). The loader is now the
>    one **generated by `napi build`** (platform detection + readable
>    error). Hand-written platform require lists are forbidden.
> 2. `glob` arrays pass through untouched (Rust `Vec<String>`), no
>    `","` joining.
> 3. `walkDirs()` actually filters to directories (the 2025 draft yielded
>    files too).
> 4. `AbortSignal` → `scanner.cancel()`; `onProgress` counted per batch;
>    collected errors surfaced.
> 5. `PathEntry.mtime` is `Date | null` (not a fake 1970 date); `hash` is
>    three-state (`undefined` / hex / `error` set).
> 6. Atomic writes create the temp file with `O_EXCL` (`flag: "wx"`) and
>    best-effort fsync the directory after rename.
> 7. `readBytes(offset, length)` supports seeking (the 2025 draft only
>    read from 0).
> 8. `home()` uses `os.homedir()` (not raw env vars).

## Core Types (`packages/path/src/types.ts`)

```typescript
import type { Serializer } from "./serializers/types.js";
import type { Path } from "./path.js";

/** Options for directory walking */
export interface WalkOptions {
  /**
   * Glob pattern(s) for file matching. AND logic if array.
   * Matched RELATIVE to the walk root (fast-glob semantics):
   * `**/*.ts` matches files at any depth, including root level.
   */
  glob?: string | string[];
  /** Regex pattern, matched against the FULL absolute path */
  regex?: RegExp;
  /** Directory names to prune (never descend into) */
  exclude?: string[];
  /** Include dotfiles/dotdirs (default: false) */
  dot?: boolean;
  /** Honor .gitignore/.ignore + parent .git dirs (default: false) */
  gitignore?: boolean;
  /** Return absolute paths (default: false → root-relative) */
  absolute?: boolean;
  /** Maximum directory depth below the root */
  maxDepth?: number;
  /** Only yield files (default: true) */
  filesOnly?: boolean;
  /** Include stat metadata (default: false) */
  withMetadata?: boolean;
  /** Compute content hash (chunked native I/O) */
  hash?: "blake3" | "sha256" | "xxhash";
  /** JS predicate filter (post-native, may be async) */
  filter?: WalkFilter;
  /** Cancellation — stops the native walk */
  signal?: AbortSignal;
  /** Progress callback (counted per batch in JS — no native cost) */
  onProgress?: (p: { scanned: number; emitted: number; bytesHashed: number }) => void;
  /** Throw collected errors at end of walk (default: false → report only) */
  throwOnError?: boolean;
  /** N-API batch size (default: 512) */
  batchSize?: number;
  /** Rust worker threads (default: CPU count) */
  concurrency?: number;
}

/** Filter predicate for walk results */
export type WalkFilter = (entry: PathEntry) => boolean | Promise<boolean>;

/** A fully populated walk result entry */
export interface PathEntry {
  readonly path: Path;
  readonly size: number;
  readonly mtime: Date | null;   // null when withMetadata is false
  readonly isFile: boolean;
  readonly isDirectory: boolean;
  readonly isSymlink: boolean;
  readonly hash?: string;        // undefined = not requested
  readonly error?: string;       // set when stat/hash failed for this entry
  relativeTo(base: Path): string;
}

/** Options for write operations */
export interface WriteOptions {
  /** Write to temp file, then atomic rename */
  atomic?: boolean;
  /** fsync before rename (only with atomic) */
  fsync?: boolean;
  /** File permissions (default: 0o644) */
  mode?: number;
  /** String encoding (default: "utf-8") */
  encoding?: BufferEncoding;
}

/** Options for read operations */
export interface ReadOptions {
  /** String encoding (default: "utf-8") */
  encoding?: BufferEncoding;
  /** Schema validator (runs after parse) */
  validate?: Validator<unknown>;
}

/** Schema validator interface */
export interface Validator<T> {
  readonly name: string;
  validate(data: unknown): T;
}
```

## Path Class (`packages/path/src/path.ts`)

```typescript
import * as pathe from "pathe";
import * as fs from "node:fs/promises";
import * as os from "node:os";
import type { Serializer } from "./serializers/types.js";
import type { WalkOptions, PathEntry, WriteOptions, ReadOptions } from "./types.js";
import { getBinding } from "./binding.js";

export class Path {
  readonly value: string;

  constructor(rawPath: string) {
    this.value = pathe.normalize(rawPath);
  }

  // ── Static Constructors ──────────────────────────────────────

  static cwd(): Path {
    return new Path(process.cwd());
  }

  static home(): Path {
    // os.homedir() over raw env vars — handles the platform-specific
    // cases (USERPROFILE / HOMEDRIVE+HOMEPATH on Windows, etc.)
    return new Path(os.homedir());
  }

  static tempDir(): Path {
    return new Path(pathe.resolve(
      process.env.TMPDIR || process.env.TMP || process.env.TEMP || "/tmp"
    ));
  }

  // ── Path Manipulation (JS-only, via pathe) ───────────────────

  join(...segments: string[]): Path {
    return new Path(pathe.join(this.value, ...segments));
  }

  resolve(...segments: string[]): Path {
    return new Path(pathe.resolve(this.value, ...segments));
  }

  relativeTo(base: Path | string): string {
    const basePath = base instanceof Path ? base.value : base;
    return pathe.relative(basePath, this.value);
  }

  get dirname(): Path {
    return new Path(pathe.dirname(this.value));
  }

  get basename(): string {
    return pathe.basename(this.value);
  }

  get extname(): string {
    return pathe.extname(this.value);
  }

  get isAbsolute(): boolean {
    return pathe.isAbsolute(this.value);
  }

  toString(): string {
    return this.value;
  }

  // ── File I/O ─────────────────────────────────────────────────

  async readText(encoding: BufferEncoding = "utf-8"): Promise<string> {
    return fs.readFile(this.value, { encoding });
  }

  /** Read `length` bytes starting at `offset` (seek supported). */
  async readBytes(offset = 0, length?: number): Promise<Buffer> {
    if (length === undefined) {
      return fs.readFile(this.value);
    }
    const handle = await fs.open(this.value, "r");
    try {
      const buffer = Buffer.alloc(length);
      await handle.read(buffer, 0, length, offset);
      return buffer;
    } finally {
      await handle.close();
    }
  }

  async read<T = unknown>(
    serializer: Serializer<T>,
    options?: ReadOptions,
  ): Promise<T> {
    const text = await this.readText(options?.encoding);
    const parsed = serializer.parse(text);

    if (options?.validate) {
      return options.validate.validate(parsed) as T;
    }

    return parsed;
  }

  async writeText(
    content: string,
    options?: WriteOptions,
  ): Promise<void> {
    if (options?.atomic) {
      await this.writeTextAtomic(content, options);
    } else {
      await fs.writeFile(this.value, content, {
        encoding: options?.encoding || "utf-8",
        mode: options?.mode,
      });
    }
  }

  async writeTextAtomic(
    content: string,
    options?: WriteOptions,
  ): Promise<void> {
    const dir = pathe.dirname(this.value);
    const tempPath = pathe.join(
      dir,
      `.${pathe.basename(this.value)}.${Date.now()}.${Math.random().toString(36).slice(2)}.tmp`,
    );

    try {
      // O_EXCL: fail (rather than clobber) if the temp name ever collides.
      // The 2025 draft used a plain writeFile — a theoretical race.
      await fs.writeFile(tempPath, content, {
        encoding: options?.encoding || "utf-8",
        mode: options?.mode,
        flag: "wx",
      });

      if (options?.fsync) {
        const handle = await fs.open(tempPath, "r+");
        try {
          await handle.sync();
        } finally {
          await handle.close();
        }
      }

      await fs.rename(tempPath, this.value);

      // Directory fsync after rename = the missing half of the atomic-write
      // durability recipe (the rename itself must hit disk). Best-effort:
      // unsupported on some platforms/FSes — never fail the write for it.
      if (options?.fsync) {
        const dirHandle = await fs.open(dir, "r").catch(() => null);
        if (dirHandle) {
          await dirHandle.sync().catch(() => {});
          await dirHandle.close().catch(() => {});
        }
      }
    } catch (err) {
      await fs.unlink(tempPath).catch(() => {});
      throw err;
    }
  }

  async write<T>(
    serializer: Serializer<T>,
    data: T,
    options?: WriteOptions,
  ): Promise<void> {
    const serialized = serializer.stringify(data);
    await this.writeText(serialized, options);
  }

  // ── Directory Operations ─────────────────────────────────────

  async mkdir(options?: { recursive?: boolean; mode?: number }): Promise<void> {
    await fs.mkdir(this.value, {
      recursive: options?.recursive ?? true,
      mode: options?.mode,
    });
  }

  async remove(options?: { recursive?: boolean; force?: boolean }): Promise<void> {
    await fs.rm(this.value, {
      recursive: options?.recursive ?? true,
      force: options?.force ?? true,
    });
  }

  async exists(): Promise<boolean> {
    try {
      await fs.access(this.value);
      return true;
    } catch {
      return false;
    }
  }

  async stat(): Promise<import("node:fs").Stats> {
    return fs.stat(this.value);
  }

  // ── Traversal ────────────────────────────────────────────────

  async *walkFiles(options: WalkOptions = {}): AsyncIterableIterator<PathEntry> {
    const binding = getBinding();
    const scanner = new binding.NativeScanner(this.value, {
      // Arrays pass through untouched — Rust owns Vec<String> + AND logic.
      // (The 2025 draft joined with ",", which globset reads as one
      // literal pattern.)
      glob: options.glob,
      regex: options.regex?.source,
      exclude: options.exclude,
      dot: options.dot,
      gitignore: options.gitignore,
      absolute: options.absolute,
      maxDepth: options.maxDepth,
      filesOnly: options.filesOnly ?? true,
      withMetadata: options.withMetadata ?? false,
      hash: options.hash,
      batchSize: options.batchSize ?? 512,
      concurrency: options.concurrency,
    });

    // Cancellation: AbortSignal → cancel the Rust walk.
    let onAbort: (() => void) | undefined;
    if (options.signal) {
      if (options.signal.aborted) {
        scanner.cancel();
      } else {
        onAbort = () => scanner.cancel();
        options.signal.addEventListener("abort", onAbort, { once: true });
      }
    }

    try {
      // Trigger the scan (runs off the JS thread — libuv pool / Tokio
      // worker, per the NAPI-RS decision table).
      await scanner.scan();

      let emitted = 0;
      let bytesHashed = 0;

      // Consume batches
      let batch = scanner.nextBatch();
      while (batch.length > 0) {
        for (const raw of batch) {
          const entry: PathEntry = {
            path: new Path(raw.path),
            size: raw.size,
            // null (not 1970!) when metadata wasn't requested
            mtime: raw.mtime ? new Date(raw.mtime) : null,
            isFile: raw.isFile,
            isDirectory: raw.isDirectory,
            isSymlink: raw.isSymlink,
            hash: raw.hash,
            error: raw.error,
            relativeTo: (base: Path | string) => {
              const basePath = base instanceof Path ? base.value : base;
              return pathe.relative(basePath, raw.path);
            },
          };

          // Apply JS predicate if present
          if (options.filter) {
            const passes = await options.filter(entry);
            if (!passes) continue;
          }

          yield entry;
          emitted++;
          if (entry.hash) bytesHashed += entry.size;
        }

        options.onProgress?.({ scanned: emitted, emitted, bytesHashed });
        batch = scanner.nextBatch();
      }

      // Surface collected errors (EACCES etc.) — never silent.
      const errors = scanner.errors();
      if (errors.length > 0) {
        if (options.throwOnError) {
          throw new AggregateError(errors, "walk reported errors");
        }
        // otherwise: reportable via a future `walk().errors()` accessor;
        // per-entry `error` fields are already populated.
      }
    } finally {
      if (onAbort && options.signal) {
        options.signal.removeEventListener("abort", onAbort);
      }
    }
  }

  /** Directories only — dedicated pass, filtered on isDirectory.
   *  (The 2025 draft set filesOnly:false with NO directory filter and
   *  yielded files too. Fixed.) */
  async *walkDirs(options: WalkOptions = {}): AsyncIterableIterator<PathEntry> {
    for await (const entry of this.walkFiles({ ...options, filesOnly: false })) {
      if (entry.isDirectory) {
        yield entry;
      }
    }
  }

  async *walk(options: WalkOptions = {}): AsyncIterableIterator<PathEntry> {
    yield* this.walkFiles({ ...options, filesOnly: false });
  }
}
```

## Key Implementation Notes

1. **All path manipulation is JS-only.** `join()`, `resolve()`, `dirname`,
   etc. use `pathe` and never cross the N-API boundary.

2. **`readText()` uses `node:fs`.** For v0.1, simple file reads use Node's
   built-in `fs.promises`. A future optimization could use the Rust engine
   for large files or Bun's `Bun.file()` when running on Bun.

3. **Atomic writes use O_EXCL temp + rename + best-effort dir fsync.**
   The temp file is created in the same directory as the target to ensure
   the rename is atomic (same filesystem); `flag: "wx"` makes name
   collisions fail instead of clobbering; the directory fsync after rename
   is the missing half of durability (best-effort across platforms).

4. **Walk batches are consumed lazily (v0.1 paging fallback).** Memory
   scales with tree size until the async-iterator spike lands (see
   code-rust-walker.md "Target: Native Async Iterator").

5. **JS `filter` is post-native.** The predicate runs after the native
   filters have already pruned the search space, minimizing boundary
   crossings.

6. **The binding loader is generated.** Never hand-write platform
   require lists; `napi build` emits the correct loader per platform.

## Decision Summary

| Decision | Rationale |
|----------|-----------|
| `pathe` for all string ops | Zero-cost; no FFI overhead for `join()` |
| `node:fs` for simple I/O (v0.1) | Proven, stable; optimize later |
| Atomic write via O_EXCL temp + rename + dir fsync | OS-level atomicity + durability; collision-safe (2026 audit) |
| Lazy batch consumption | Clean async iterator; bounded by prefetch once the iterator spike lands |
| Generated NAPI-RS binding loader | Hand-written self-require was a circular-load bug (2026 audit) |
| `AbortSignal` + `onProgress` + error surfacing | Cancellation, observability, and visible failures (2026 audit) |
| `Serializer<T>` as separate interface | Composable; independent of `Path` |
| JSON stays in JS | V8 `JSON.parse()` is faster than Serde→N-API |
| `filter` is post-native | Documented trade-off; flexibility over speed |
